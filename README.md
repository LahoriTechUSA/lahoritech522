# Lahori Tech Website

A professional, high-performance landing page for Lahori Tech. 

## Deployment Guide
This repository is fully static and ready to be deployed on platforms like GitHub Pages, Vercel, Netlify, or any standard web hosting.

1. Clone this repository.
2. Ensure the file `IMG_0543.PNG` (the Lahori Tech logo) is placed in the root directory.
3. Deploy directly to your hosting provider.

## Features
* Modern animated interface
* Black and gold metallic brand aesthetic
* Mobile responsive layout
* Contact form UI
